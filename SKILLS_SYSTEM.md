# Finalist Arena - Skills & Manual Books System

## Skill Manuals
Found as loot across all arena biomes. Each manual teaches a human trait/scavenged skill and upgrades based on playstyle.

### Example: Archery Manual
- **Base (untrained):** 30% miss chance, no weak spot highlighting
- **Tier 1 (50 bow kills):** Miss chance 20%, weak spot glow on enemies
- **Tier 2 (150 bow kills):** Miss chance 10%, bullet drop prediction
- **Tier 3 (300 bow kills):** Miss chance 5%, weak spot critical damage x2

### Other Manuals
- **Medicine Manual:** Craft better meds, faster healing, revive teammates
- **Stealth Manual:** Reduced noise, crouch movement, camouflage crafting
- **Survival Manual:** Slower need decay, water purification, shelter building
- **Combat Manual:** Melee damage, execution animations, parry
- **Crafting Manual:** Unlock advanced recipes, reduce material costs
- **Tracking Manual:** See footprints, scent trails, AI detection radius
- **Paranoia Resistance Manual:** Reduce paranoia gain, resist Echo Scream
- **Climbing Manual:** Faster climb, wall run, ledge grab
- **Swimming Manual:** Faster swim, longer breath hold, underwater loot

## Upgrade Logic
Skill XP earned by using that playstyle. Manuals found in world unlock the skill tree. Playstyle-specific progression (e.g., archery kills upgrade archery, not melee).
